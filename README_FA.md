## 📌 مرور کلی دوره

این دوره سال‌ها تجربه در ساخت و استقرار سیستم‌های LLM در مقیاس بزرگ را — از مدل‌های مورد استفاده در جستجوی گوگل تا معماری‌های عاملی پشت Gemini — در یک برنامه درسی متمرکز و عملی برای نسل بعدی مهندسان هوش مصنوعی خلاصه کرده است.

هر جلسه **۴۰ دقیقه کدنویسی عملی خالص** است. بدون اسلاید. بدون سخنرانی. دانشجویان از دقیقه اول کد با کیفیت تولید می‌نویسند و به تدریج به سمت ساخت یک دستیار هوش مصنوعی کاملاً یکپارچه پیش می‌روند که تولید تقویت‌شده با بازیابی (RAG)، استفاده خودکار از ابزار و حفاظ‌های ایمنی بلادرنگ را ترکیب می‌کند.

> **فلسفه:** *«بهترین راه برای درک مدل‌های زبانی بزرگ، ساختن با آنهاست. تئوری از شهود پیروی می‌کند و شهود از کد می‌آید.»*

## 📚 جزئیات جلسات

### جلسه ۱ — مبانی API مدل‌های زبانی بزرگ
**`persian_notebooks/session_1_llm_api_fundamentals.ipynb`**

> راه‌اندازی کلاینت پایتون OpenAI و تسلط بر Chat Completions API.

- نصب و پیکربندی SDK `openai` با مدیریت امن کلیدها
- درک سه نقش پیام: `system`، `user`، `assistant`
- تنظیم تولید با `temperature`، `max_tokens` و `top_p`
- پیاده‌سازی پاسخ‌های جریانی (streaming)
- ساخت تابع کمکی `chat()` قابل استفاده مجدد

**تمرین:** ساخت مترجم چندزبانه با سطوح رسمیت قابل تنظیم.

---

### جلسه ۲ — مهندسی پرامپت در عمل
**`persian_notebooks/session_2_prompt_engineering.ipynb`**

> تسلط بر هنر و علم گرفتن دقیقاً آنچه از LLM می‌خواهید.

- **Zero-shot** — اجرای مستقیم وظیفه بدون مثال
- **Few-shot** — آموزش با نمایش و مثال‌های انتخاب‌شده
- **Chain-of-Thought (CoT)** — باز کردن قفل استدلال چندمرحله‌ای با «قدم به قدم فکر کن»
- الگوهای طراحی سیستم پرامپت: تخصیص نقش، محدودیت‌ها، مشخصات قالب
- قالب‌های پرامپت قابل استفاده مجدد با f-strings پایتون

**تمرین:** مقایسه zero-shot، few-shot و CoT در تحلیل احساسات بررسی محصول.

---

### جلسه ۳ — خروجی‌های ساختاریافته و تجزیه خروجی
**`persian_notebooks/session_3_structured_outputs.ipynb`**

> استخراج داده‌های قابل اعتماد و قابل خواندن توسط ماشین از LLMها — پایه هر خط لوله تولید.

- حالت JSON با `response_format: json_object`
- شِماهای سخت‌گیرانه با `json_schema` برای تضمین نوع فیلدها
- تجزیه مقاوم با اعتبارسنجی و مدیریت خطای ظریف
- خطوط لوله پردازش دسته‌ای برای استخراج ساختاریافته در مقیاس

**تمرین:** ساخت استخراج‌کننده اطلاعات رزومه/CV با خروجی JSON معتبر.

---

### جلسه ۴ — امبدینگ‌های متنی و جستجوی معنایی
**`persian_notebooks/session_4_embeddings_semantic_search.ipynb`**

> تبدیل متن به معنای ریاضی — سپس جستجو بر اساس *مفهوم*، نه کلمه کلیدی.

- تولید امبدینگ‌های ۱۵۳۶ بُعدی با `text-embedding-3-small`
- پیاده‌سازی شباهت کسینوسی: $\cos(\theta) = \frac{\mathbf{A} \cdot \mathbf{B}}{\|\mathbf{A}\| \|\mathbf{B}\|}$
- ساخت موتور جستجوی معنایی از صفر با NumPy
- نمایش برتری نسبت به تطبیق کلمه کلیدی در پرسش‌های مبهم

**تمرین:** ساخت پایگاه دانش پرسش‌های متداول با درک معنایی.

---

### جلسه ۵ — تولید تقویت‌شده با بازیابی (RAG)
**`persian_notebooks/session_5_rag.ipynb`**

> به LLM خود مغز بدهید — پاسخ به سؤالات بر اساس اسناد خودتان.

- معماری RAG سرتاسری: **تکه‌بندی ← امبد ← ایندکس ← بازیابی ← تولید**
- تکه‌بندی هوشمند اسناد با همپوشانی برای تداوم زمینه
- کلاس `SimpleRAG` با متدهای `add_document()`، `retrieve()` و `ask()`
- تست مرزی: تأیید اینکه مدل برای پرسش‌های خارج از محدوده «نمی‌دانم» می‌گوید
- مقیاس‌پذیری چندسندی و گسترش پایگاه دانش

**تمرین:** ساخت چت‌بات پرسش و پاسخ روی مجموعه اسناد سفارشی.

---

### جلسه ۶ — فراخوانی تابع و استفاده از ابزار
**`persian_notebooks/session_6_function_calling.ipynb`**

> به LLMها یاد بدهید فراتر از متن بروند — فراخوانی APIها، پرسش از پایگاه‌های داده، اجرای کد.

- جریان فراخوانی تابع: **کاربر → LLM → فراخوانی ابزار → اجرا → نتیجه → LLM → پاسخ**
- تعریف شِماهای ابزار با مشخصات پارامتر JSON
- مدیریت فراخوانی‌های تکی و موازی ابزار در یک پاسخ
- پیاده‌سازی ابزارهای ماشین‌حساب، آب‌وهوا و تاریخ/ساعت
- معماری ثبت و ارسال ابزار بدون وقفه

**تمرین:** ساخت دستیار جستجوی محصول با ابزار سفارشی `search_products`.

---

### جلسه ۷ — ساخت عامل‌های LLM
**`persian_notebooks/session_7_building_agents.ipynb`**

> از استفاده از ابزار تا خودمختاری — ساخت عامل‌هایی که استدلال، برنامه‌ریزی و عمل می‌کنند.

- الگوی **ReAct**: **مشاهده → فکر → عمل → تکرار**
- پیاده‌سازی حلقه عامل خودمختار با محافظ حداکثر تکرار
- ابزارها: ماشین‌حساب، جستجوی پایگاه دانش، نرخ ارز
- کلاس `ConversationalAgent` با حافظه مکالمه پایدار
- استدلال چندمرحله‌ای در فراخوانی‌های زنجیره‌ای ابزار

**تمرین:** حل پرسش‌های پیچیده چندمرحله‌ای (محاسبات تراکم، مقایسه‌های بین‌کشوری، تحلیل سرانه).

---

### جلسه ۸ — الگوهای پیشرفته و بهترین شیوه‌ها
**`persian_notebooks/session_8_advanced_patterns.ipynb`**

> استحکام‌بخشی اپلیکیشن‌های LLM با الگوهای مورد استفاده در مقیاس گوگل.

- **زنجیره‌سازی LLM** — خطوط لوله چندمرحله‌ای: خلاصه‌سازی → استخراج موجودیت → تولید خلاصه اجرایی
- **حفاظ‌های ورودی** — تشخیص تزریق پرامپت، فیلتر کردن خارج از موضوع، تعدیل محتوا
- **مدیریت هزینه** — شمارش توکن، ردیابی مصرف، تخمین هزینه هر درخواست
- **LLM به عنوان داور** — ارزیابی خودکار خروجی با امتیازدهی مبتنی بر معیار
- **تلاش مجدد با پشتیبان** — عقب‌نشینی نمایی برای تاب‌آوری API

**تمرین:** ساخت خط لوله محتوای تعدیل‌شده: بررسی ایمنی → تولید → ارزیابی.

---

### جلسه ۹ — پروژه نهایی: اپلیکیشن کامل LLM
**`persian_notebooks/session_9_capstone.ipynb`**

> یکپارچه‌سازی بزرگ — هر مفهوم از هر جلسه، متحد در یک سیستم.

- کلاس **`SmartAssistant`** ترکیبی از RAG + فراخوانی تابع + حلقه عامل + حفاظ‌ها + حافظه
- پایگاه دانش ۱۰ سندی (داده‌های شرکت TechNova: محصولات، قیمت‌گذاری، درآمد، رقبا)
- سه ابزار یکپارچه: جستجوی دانش، ماشین‌حساب، تحلیل رقبا
- خط لوله ایمنی ورودی با تعدیل بلادرنگ
- حلقه مکالمه تعاملی با حافظه جلسه
- شش سناریوی نمایشی پیشرو برای تست هر قابلیت

**تمرین:** گسترش دستیار با ابزار جدید یا منبع دانش اضافی.

## 🚀 شروع کار

### پیش‌نیازها

- Python 3.11 یا جدیدتر
- کلید API از OpenAI (یا endpoint سازگار)
- Jupyter Notebook / JupyterLab / VS Code با افزونه Jupyter

### نصب

```bash
# کلون کردن مخزن
git clone https://github.com/your-org/sariau-llm-course-spring-2026.git
cd sariau-llm-course-spring-2026

# نصب وابستگی‌ها
pip install openai numpy python-dotenv

# پیکربندی کلید API
cp .env.example .env
# فایل .env را ویرایش کنید و OPENAI_API_KEY خود را اضافه کنید
```

### پیکربندی محیط

یک فایل `.env` در ریشه پروژه ایجاد کنید:

```env
OPENAI_API_KEY=your-api-key-here
MODEL_NAME=gpt-4o-mini
```

### اجرای نوت‌بوک‌ها

```bash
# اجرای Jupyter
jupyter notebook

# یا استفاده از VS Code
code .
# هر فایل session_*.ipynb را باز کنید
```

> **نکته:** جلسات را به ترتیب دنبال کنید. هر نوت‌بوک بر مفاهیم جلسات قبلی بنا شده و پروژه نهایی (جلسه ۹) همه چیز را یکپارچه می‌کند.
